# 用八部原书复建

在 Windows x64 上安装 CPython 3.14 x64。独立审计还会从 PATH 调用 PowerShell 7.6 或更高版本的 `pwsh`。这个目录自带 MDX/MDD 写入器、HTML5 解析器、GoldenDict 查找表、LZO 2.10 和回归用例。原书目录的八个文件名见 `merge_dictionaries.py` 的 `SOURCES`。

在本目录打开 PowerShell。把 `$originalBooks` 改成含「中日」「英语」两个子目录的原书根目录。每次复建使用一个新工作目录，原先的工作目录可留作对照。完整过程会产生数 GB 的临时数据库。

```powershell
$originalBooks = 'D:\原书根目录'
$env:CONDA_PREFIX = (Resolve-Path '.tools/lzo').Path
$env:E_SEARCH_MERGE_READER_EXE = (Resolve-Path '../app/E_Search.exe').Path
py -3.14 -B -X utf8 mdict_io.py --self-test
py -3.14 -B -X utf8 merge_dictionaries.py self-test
py -3.14 -B -X utf8 -m unittest test_merge_render.py
py -3.14 -B -X utf8 audit_merged.py --self-test
py -3.14 -B -X utf8 merge_dictionaries.py stage --source-root "$originalBooks" --stage '.work/A/stage'
py -3.14 -B -X utf8 merge_dictionaries.py build --stage '.work/A/stage' --output '.work/A/book'
py -3.14 -B -X utf8 audit_merged.py --source-root "$originalBooks" --lookup-profile goldendict --check-dom --control-index-report 'reports/GoldenDict-补入口前.json' --stage '.work/A/stage' --books '.work/A/book' --output '.work/A/independent.json'
```

若需检验可重现性，再选择 `.work/B` 运行一次 stage 和 build，然后执行下列命令。工具对 A、B 各自的词头、正文、改写、资源和文件哈希作比较。原书基准、两卷元数据和版本化的依赖指纹会记录在输出目录 `audit.json`。

```powershell
py -3.14 -B -X utf8 merge_dictionaries.py compare '.work/A/book' '.work/B/book'
py -3.14 -B -X utf8 merge_dictionaries.py export-evidence --stage '.work/A/stage' --books '.work/A/book' --output '.work/A/逐条溯源.zip'
```

写入器为 mdict-utils 1.3.14，使用其公开发行包内 writemdict 的打包代码。HTML5 检查使用 selectolax 1.0.2（MIT）和 Lexbor（Apache 2.0）。两份原始 wheel 保留了各自的许可文件。LZO 使用本机 Conda 的 2.10 版（GPL v2+）。GoldenDict 表来自 `bd959482644d7cfa57743a5143d2a5d0462e382d`（GPL v3+）；Unicode 5.0.0 的数据版权及使用条款保留在 `DerivedAge-5.0.0.txt` 头部。其他随附许可见 `licenses`。
