# 打开合并词书

**使用 SearchBar_Edwin**　双击同目录的「打开合并词书.cmd」。按 1 查中英卷，按 2 查日语卷，按 3 同时检索两卷。在浮窗输入词语，按 Tab 展开正文。每个来源段显示书名和原书序号。点击段内链接后，可用「返回上一个词条」回看原文。

可先试中英卷的 `apple` 和 `苹果`。日语卷可试 `食べる`、`たべる`、`taberu`、`食べました`。英辞郎归在日语卷里，输入 `absquatulate` 可看英日释义。

**使用 GoldenDict**　在「编辑 → 词典」中添加本交付目录下的 `books` 文件夹，让 GoldenDict 建立索引。两份 MDX 与日语卷的同名 MDD 放在一起。这个入口只需要 `books`，不用打开 E_Search。两个卷可同时包含同名词，来源名和原书序号印在释义前。GoldenDict 打开来源专用跳转页时，标签页或历史记录会显示以 `esref-` 开头的内部词头。

**移动或备份**　连同 `app`、`books`、`index` 和启动脚本一起复制，就能继续使用现成的检索库。只保留 `books` 也能在其他兼容阅读器里使用。程序随附 Windows x64 的 .NET 运行时，SearchBar_Edwin 富文本详情使用本机 Microsoft Edge WebView2 Runtime。

**内容范围**　中英卷按牛津高阶英汉双解第 7 版、现代汉英综合大辞典的顺序排列。日语卷先收小学馆 V2 日汉，随后是三省堂、新世纪、三合一、英辞郎和小学馆 V2 中日。按原始词头组合来源，保留各书的释义、例句和顺序。八本原书里已有的缺图、缺样式与断链见 `verification/归档-首轮显示修订/归档-20261123/词书合并验收.md`。

**复建与核对**　第二轮以首轮实际交付的双卷为输入，使用提交 `1b273e7` 阅读器的 `export-display-rules` 和复建工具的 `--repair-layout` 生成。[复建工具说明](复建工具/使用说明.md)给出输入卷哈希与完整命令。[双卷验收报告](verification/词书合并验收.md)记录本轮修改和实测，[索引自检](verification/交付索引自检.json)与[交付文件哈希](verification/交付文件哈希.json)可核对当前包。首轮核验保存在[首轮验收归档](verification/归档-首轮显示修订/词书合并验收.md)，其中的 `归档-20261123` 留存初次合并时的原书对账和阅读器实测。
