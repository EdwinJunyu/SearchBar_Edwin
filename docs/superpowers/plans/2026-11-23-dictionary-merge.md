# 两卷词书实施计划

依据同日《E_Search 两卷词书合并设计》和 HANDOFF-2，在项目目录构建与验证，个人数据库保留作对照。

- [x] **真实输入与二进制读写**。`mdict_io.py` 逐物理位置严格读取 MDX/MDD，校验块长度、校验和与编码。输出采用 V2、UTF-8、zlib。以重复键、空正文、跨块字符、MDD 和篡改块作回归。已有 `MdxReader.cs` 提供独立读回路径。
- [x] **合并与来源映射**。`merge_dictionaries.py` 以磁盘暂存八本，分别构建两卷。原词头精确分组，原序号从 1 开始。不同来源或同源歧义先保留。候选共享须核对正文、上下文与唯一性。每条公开记录携带可逆的原文来源清单，供导入和独立核对。原书缺失的图、样式和跳转记录在案。
- [x] **渲染和资源**。识别真实语料出现的 HTML 属性，对源内目标、片段和资源路径逐处改写；在目标书中保留各来源的原段、排序、原引用和有效资源。对缺失的 `sf_cb.css`、牛津图和损坏的内嵌图分开核对。
- [x] **E_Search 导入与查词**。在现有 `DictionaryStore.cs`、`Program.cs` 等文件接入两卷。通过来源元数据复用原书解析器，复验精确词头、日语读音或罗马字、补充独有词和同源跳转。详情同时支持来源、富文本和包内资源。回归加到项目已有体系。
- [x] **独立审计与交付**。从原书与成品分别读取，比对全部来源、逐条原文和资源字节，核对改写、共享及顺序。比较两次构建与完整目录，执行真实 GoldenDict 和 E_Search 验收，记录耗时、覆盖率和遗留问题。未解释差异阻断整套发布。
