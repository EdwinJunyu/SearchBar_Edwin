# E_Search 两卷词书合并设计

## 交付范围

从当前启用的八本 MDX 原档构建两部可独立打开的 V2 UTF-8 词典，配套资源随同名 MDD 交付。中英卷先展示牛津高阶英汉双解第 7 版，再展示现代汉英综合大辞典。日语卷依次使用小学馆 V2 日汉、三省堂超级大辞林第二版、新世纪日汉双解、三合一日语、英辞郎 v86 英和、小学馆 V2 中日。每段标注实际来源，保留英日、日英和日语单语内容。

## 已选择的方案

用户选择了两卷并适配 E_Search。将英辞郎独立分卷可以单列英日方向，但会多出一部需要管理的词书。只交付词书、在 GoldenDict 查看排版，则 E_Search 的通用导入器会失去八本原有的部分读音、别名和排版信息。采用两卷加应用适配，可沿用两种查词工具。

## 合并与应用

1. 从八本原档逐物理序号抽取，登记文件哈希、原编码、头部、原始词头、正文和资源。新世纪的 MDD、同目录 CSS 和封面随源核对。原书中已经缺少的资源或链接单独登记。
2. 同卷中仅按词头原始 Unicode 码点分组。按来源优先级和原序号保留所有版本。只有正文与样式、资源和有序跳转目标均可证明等价时才共享展示。每条原记录保留可逆的来源映射。跨书同名路径、链接和片段先按原书解析，再指向成品内的对应位置。
3. E_Search 导入后保留每个来源的词头、读音、别名与原有查找方式。详情可看到主书原文和补充段，进入同源跳转并读取已打包的资源。普通旧词书沿用现有入口。对比在独立测试库中进行。
4. 使用本机 GoldenDict 1.5.0-RC2-254-gbd95948 和 E_Search 验证。以独立读取路径枚举原书与成品，逐词条、段落、资源核对，比较两次同输入构建的逻辑结果，另测真实查词、跳转和呈现。合成数据只用于回归测试。

## 交付条件

两卷在同一暂存版本构建，完成全量核对后一起交付。报告列出每本覆盖率、重复与独有内容、输入原有异常和客户端实测结果。任何无法解释的内容差异保留原始证据并阻断发布。工具选型、构建目录及索引实现按真实数据确定。个人活动数据库的切换属于独立部署操作。
