# 日语词典分发优化与 6,000 词速度对照

2026-11-24 · Windows x64 · 对照版本 `98798b6`

## 下载和首次使用

本次只改变日语卷在 Windows 完整 ZIP 中的表示。原始日语 MDX 为 **940,291,094 字节**，新包中的 MDXP 为 **571,079,646 字节**，日语卷减少 **352.11 MiB（39.27%）**。完整 ZIP 从 **1.448 GiB** 降至约 **1.104 GiB**，少下载约 **23.7%**。安装后仍使用原大小的 MDX。

| 同机实测 | 旧版 | 新版 |
|---|---:|---:|
| 全新个人目录，桌面首次准备词库 | 3.01 秒 | 18.12 秒 |
| 同进程再次定位已安装的个人库 | 0.40 毫秒 | 0.47 毫秒 |

首装对照分别在独立进程内调用桌面使用的 `FindDatabase` 默认路径，每版各测一次，计入复制数据库、准备双卷与资源及发布个人库的时间。两次计时保留操作系统文件缓存。再次定位仅测数据库路径检查。它们与下表的查词时间独立。实际打开窗口的绘制和 WebView2 初始化未计入。

## 词典如何还原

合并词页既保存原书记录，也保存用于显示的 HTML。制作发布包时，把原书记录从 Base64 还原成 JSON 字节，和 HTML 相邻压缩。逐块预先检查能否重建原始字节，且仅在结果更小时才保存这种表示。日语卷共 71,999 个正文块，其中 62,644 个使用紧凑编码，9,355 个原样保存。中英卷、资源和随包的 SQLite 数据库仍采用原格式。

全新桌面安装使用固定版本的 zlib-ng 2.2.4，以最多六个工作线程分批还原，再按原顺序写入。只有整卷 SHA-256 与词库引用相同，才发布个人库。已有个人库直接复用。需要预先安装时可在解压目录运行 `E_Search.exe install-seed`。还原出的日语卷 SHA-256 为 `A875B81B4F7961158FCB0952F33E5FF9439204527ACCE93DCDC156D5DC7827A8`。

## 查词测试

从 wordfreq 日语词频数据与实际词典词头的交集中固定抽取 6,000 个不同查询。按 Zipf 词频分三层，每层各 2,000 个。高频为 ≥4.5，中频为 ≥3 且 <4.5，低频为 <3。高频例子有「料理」「財布」，中频有「痛感」「花婿」，低频有「英虞湾」「販路」。低频以语料统计为准。

在同一台 Windows 11、Intel Core i9-13900H 上，使用 PowerShell 7.6.9 / .NET 10.0.14 测试宿主，从旧发布程序和新发布候选分别加载真实查词程序集。旧版读原种子，新版读从实际 ZIP 首装出的个人库。每个独立进程预热 64 次，再计时 6,000 词。按 ABBA、BAAB 顺序交替运行，两版各四轮，共 **48,000 次查词和 48,000 次正文读取**。同轮次新旧版采用相同词序。查询覆盖全部已启用词典，每次选第一条日语命中读取原书正文。用 SHA-256 比较双方返回的有序结果和完整正文，用预先冻结的词典条目 ID 核对命中。计时包含测试宿主调用后端方法的开销。摘要计算和写 CSV 放在计时区间外。

| 指标（毫秒） | 旧 P50 | 新 P50 | 旧 P95 | 新 P95 | 旧 P99 | 新 P99 |
|---|---:|---:|---:|---:|---:|---:|
| 全部 · 查词 | 0.954 | 0.963 | 3.008 | 2.754 | 4.873 | 4.537 |
| 全部 · 读取正文 | 0.282 | 0.281 | 0.568 | 0.555 | 1.821 | 1.734 |
| 全部 · 两项合计 | 1.284 | 1.295 | 3.559 | 3.271 | 5.614 | 5.169 |
| 高频 · 两项合计 | 1.396 | 1.402 | 4.076 | 3.769 | 7.064 | 6.490 |
| 中频 · 两项合计 | 1.275 | 1.280 | 3.408 | 3.104 | 5.009 | 4.589 |
| 低频 · 两项合计 | 1.207 | 1.217 | 3.190 | 2.917 | 4.754 | 4.263 |

P50 为中位数，P95、P99 分别是第 95、99 百分位。查词加正文读取的 P50 从 1.284 毫秒变为 1.295 毫秒，P95 从 3.559 毫秒变为 3.271 毫秒。上述差异描述本次实测。两版在安装完成后都读取相同的标准 MDX。

## 正确性和复核

每轮均有 6,000/6,000 个查询命中预期条目且读到非空正文。新旧版的返回数量、结果顺序及内容、首个日语条目 ID 和正文摘要差异均为 0。首条正文来自小学馆 4,159 词、三省堂 1,354 词、新世纪 229 词、三合一日语辞典 258 词。

Windows 与后端 Release 构建通过，15 项 Python 测试通过。标准回归正常退出（56 行 PASS），新 ZIP 内八部词典的 11 项发布样本全部通过。另用小型双卷验证四进程并发首次安装、显式种子路径、只读输入、损坏后重试以及既有个人库复用。

复测时，一次临时目录误指项目树，导致开发库的牛津分区被测试词条替换。该分区已从四份相互一致的历史备份恢复。复核了 42,481 条正文与 42,481 个索引键。其余七书和设置逐行一致，SQLite 完整性与外键检查通过。回归已增加项目树外临时目录检查。基准使用独立发布种子与首装副本。

原始数据在项目根目录下的 `.归档-旧构建与测试-20261124/.data/japanese-release-comparison/`。其中 `cases.json` 保存词表，`bench.ps1` 和 `run.ps1` 是测量脚本，`old-*.csv`、`new-*.csv` 保存逐词数据，`summary.json` 保存分层、分轮统计及差异。冻结词表 SHA-256 为 `2957014709bd9f8b2b8404c10839ed915773843c70c72a551781e0defd976c4d`。本报告的性能范围是本机安装完成后的查词与原文读取，未测物理冷盘、全量桌面交互或其他处理器。
